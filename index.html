Tetapan Storan Fail (Google Drive)

Sambungkan Web App ini dengan folder Google Drive untuk menyimpan data dan fail imej kad baucar.

Cara Menetapkan Storan Google Drive:

  1. Buka Google Drive (drive.google.com).
  2. Bina Folder Baru (contoh: "Data Baucar Digital").
  3. Buka folder tersebut dan salin ID di hujung URL bar alamat: drive.google.com/drive/folders/1A2b3C4d5E6f7G8h9I0jKLMN
  4. Tampal ID tersebut di atas dan klik **Simpan ID Folder Drive**.

Pautan Webhook Google Apps Script

Sambungkan sistem ke Google Sheet untuk merekodkan tuntutan pelanggan & menyimpan imej kad baucar ke Drive.

Skrip Google Apps Script (Dengan Menyimpan Imej Kad): 

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    var fileUrl = "Tiada Fail";
    
    if (data.folderId && data.cardBase64) {
      try {
        var folder = DriveApp.getFolderById(data.folderId);
        var base64Data = data.cardBase64.replace(/^data:image\/(png|jpeg);base64,/, "");
        var blob = Utilities.newBlob(Utilities.base64Decode(base64Data), 'image/png', 'Baucar_' + data.code + '_' + data.name + '.png');
        var file = folder.createFile(blob);
        file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
        fileUrl = file.getUrl();
      } catch (driveErr) {
        fileUrl = "Ralat Drive: " + driveErr.toString();
      }
    }

    sheet.appendRow([
      data.code, data.name, data.email, data.phone, 
      data.ic, data.tierName, data.value, data.date, 
      data.status, fileUrl
    ]);
    
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch (err) {
    return ContentService.createTextOutput("Error: " + err.toString()).setMimeType(ContentService.MimeType.TEXT);
  }
}
